# Overview

This project analyzes a dataset of Netflix movies and TV shows to uncover trends, patterns, and insights using Python. 
It demonstrates how to clean data, explore it visually, and extract meaningful conclusions about the platform's content library.

# Objectives

- Perform data cleaning (handling missing values, duplicates, and incorrect datatypes).
- Analyze content distribution by year, genre, and language.
- Identify top-rated and most popular titles.
- Visualize findings with clear, interactive plots.

# Dataset

- File name: mymoviedb.csv (or Netflix dataset)
- Columns include: Release_Date, Title, Overview, Popularity, Vote_Count, Vote_Average, Original_Language, Genre, Poster_Url

# Technologies Used

- Python Libraries: pandas, numpy, matplotlib, seaborn
- Jupyter Notebook for exploratory analysis

# Key Steps

1. Data Cleaning
Removed NaN values and duplicates
Converted date columns to proper datetime format
Standardized datatypes for analysis

2. Exploratory Data Analysis (EDA)
Movies released by year, genre, and language
Correlation between popularity, ratings, and vote count

3. Visualization
Bar charts, Tables , and Cat plots
Top-performing content highlighted with charts

# Insights

- Which year had the highest number of releases?
- What genres dominate Netflix's catalog?
- Are high vote counts strongly correlated with high ratings?
- Which movies/shows are the most popular globally?
